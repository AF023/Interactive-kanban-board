# 📋 TaskFlow Studio - Interactive Kanban Task Board

[![Live Demo](https://img.shields.io/badge/Live_Demo-Agile_Task_Board-7C3AED?style=for-the-badge&logo=github)](https://af023.github.io/interactive-kanban-board/)

## 📌 Overview
TaskFlow Studio is an interactive **Agile Kanban Task Board** designed with a clean, studio-minimalist UI theme. 

Built with HTML5, Tailwind CSS, and vanilla JavaScript, it features real-time client-side state management, DOM manipulation, and data persistence via the browser's `localStorage` API. Users can create task cards, progress them through workflow columns (To Do, In Progress, Done), and toggle language preferences dynamically (PT/EN).

---

## ✨ Key Features
- **LocalStorage Data Persistence:** Automatically saves and restores workflow state across browser reloads.
- **Dynamic Kanban Swimlanes:** Smooth card movement between "To Do", "In Progress", and "Done" states.
- **Clean Studio Aesthetic:** Refreshing light-theme UI designed with Tailwind CSS, soft shadows, and clean card borders.
- **Bilingual Support (i18n):** Real-time language switcher between English and Portuguese for all interface components.
- **Interactive Controls:** Instant card creation, deletion, and column counter logic.

---

## 🛠️ Tech Stack
- **Markup:** HTML5 (Semantic).
- **Styling:** Tailwind CSS (Responsive grid, modern light-theme UI).
- **Logic & State:** Vanilla JavaScript (ES6+, DOM Manipulation, LocalStorage API).
- **Icons:** Lucide Icons.
